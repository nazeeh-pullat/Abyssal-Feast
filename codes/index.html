Codes & Gifts

Redeem codes unlock rewards in Abyssal Feast: shells, fish, accessories and more.

Where do I find codes?
  • Codes are given out in our Abyssal Feast Discord server, in events, giveaways and updates.
  • Each code is secret, random and can have a limited number of uses, so redeem it quickly.

Join the Abyssal Feast Discord

How to redeem a code

  1. Open Abyssal Feast and go to the Shop.
  2. Open the Redeem tab.
  3. Type or paste your code into the box and tap Redeem.
  4. The reward is added to your save straight away.

Good to know

  • You need an internet connection to redeem a code, it is checked by our server.
  • A code can only be used once per device.
  • Codes only come from us. We will never ask for a password or payment details.
  • The only data sent is the code and a random device ID, see the Privacy Policy.
